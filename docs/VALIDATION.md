# v5 验证记录

验证日期：2026-11-11。以下为本机自动化测试和模拟图像结果，不代表真实印刷品的检测率。

- 24 项单元及 API 测试通过，覆盖 CRC、Hamming、交织、外轮廓、默认入口、格式认证、哈希、计数并发与幂等。
- 默认 HTTP 入口经实际 uvicorn 启动、健康检查、multipart 上传验证，样本编号 `13800138000` 返回 accepted=true 和验证次数 1。
- 三个边界/常用编号的像素 SHA-256 和母版标识由回归测试固定。

## 模拟照片集

固定种子生成 108 张有码图和 12 张无码图，包括 2400 × 1800 与 1800 × 2400 的完整照片画幅。结果为 98 张有码图正确接受、10 张拒绝；12 张无码图全部拒绝，未观察到错误号码被接受。
